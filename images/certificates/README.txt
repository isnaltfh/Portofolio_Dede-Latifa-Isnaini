To add a new certificate:
1. Save the image here, e.g. my-new-cert.jpg
2. In index.html copy one <button class="cert"> block into the row that fits and change
   the image name, the issuer · year and the title.
   For a portrait document add cert__thumb--portrait next to cert__thumb.
