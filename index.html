AI / RAG · Final Project · Apr – Jul 2026

PLN NP Internal RAG Chatbot

The problem

Technical answers were spread across 74 PDF manuals totaling 20,573 pages, so finding the right procedure took a long time.

What I built

  • FastAPI backend and a ChromaDB retrieval pipeline with BAAI/bge-m3 embeddings.
  • LLM answers via Ollama (Qwen2.5) with document references.
  • Request cancellation for long-running questions.
  • Deployment on a Linux VM with Nginx and systemd.

Result

  • Evaluated with 20 questions validated by PLN technical personnel.
  • 0.83 Faithfulness and 1.00 Context Recall.
  • Response time cut from ~6 minutes to under 3 minutes per query.

My role

End-to-end: development, evaluation, optimization and deployment.
